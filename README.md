# 🌙 엘더문 온라인 (Eldermoon Online)

모바일 브라우저에서 바로 즐기는 **3D MMORPG**입니다. 앱 설치 없이 휴대폰 브라우저로 접속해 다른 플레이어와 함께 사냥하고, 퀘스트를 깨고, 장비를 모으며 성장할 수 있습니다.

- **클라이언트**: Three.js (WebGL), 순수 ES 모듈 — 빌드 과정 없음
- **서버**: Node.js + WebSocket (`ws`), 서버 권위(authoritative) 방식 시뮬레이션
- **오프라인 모드**: 서버가 없어도 같은 게임 로직이 브라우저 안에서 돌아가 혼자 플레이 가능

## 빠른 시작

```bash
npm install
npm start
```

서버가 켜지면 콘솔에 주소가 표시됩니다.

- PC: `http://localhost:3000`
- 휴대폰: 같은 Wi-Fi에서 콘솔에 표시된 `http://192.168.x.x:3000` 주소로 접속

> 휴대폰은 **가로 모드**를 권장합니다. 브라우저 메뉴의 "홈 화면에 추가"를 하면 전체 화면 앱처럼 실행됩니다(PWA).

### 환경 변수

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `3000` | 서버 포트 |
| `HOST` | `0.0.0.0` | 바인딩 주소 |
| `BOTS` | `8` | 월드를 돌아다니는 AI 모험가 수 (`0`이면 없음) |
| `DATA_DIR` | `./data` | 캐릭터 저장 파일(`players.json`) 위치 |

### 정적 호스팅 (오프라인 전용)

```bash
npm run build:static   # dist/ 생성
```

`dist/` 폴더를 GitHub Pages 같은 정적 호스팅에 올리면 서버 없이 오프라인 모드로 플레이할 수 있습니다. 진행 상황은 브라우저(localStorage)에 저장됩니다.

## 게임 소개

### 직업
| 직업 | 특징 | 스킬 |
| --- | --- | --- |
| 🛡️ 전사 | 높은 체력과 방어력, 근접 공격 | 강타 · 회오리 베기(범위) · 전투 함성(버프+회복) |
| 🔮 마법사 | 원거리 마법, 아군 치유 | 화염구 · 서리 폭발(범위+둔화) · 치유의 빛(범위 회복) |
| 🏹 궁수 | 빠른 연사와 높은 치명타 | 관통 사격 · 화살비(지점 범위) · 바람의 질주(이동/공격 속도) |

### 월드
마을을 중심으로 방향마다 다른 사냥터가 펼쳐집니다. 지역에 들어가면 하늘·안개 색이 바뀝니다.

| 지역 | 위치 | 레벨 | 몬스터 |
| --- | --- | --- | --- |
| 엘더문 마을 | 중앙 | 안전 지대 | 촌장(퀘스트), 상인(상점), 사제(치유) |
| 속삭이는 초원 | 마을 주변 | 1-4 | 초록 슬라임 |
| 서리솔 숲 | 북쪽 | 4-8 | 회색 늑대 |
| 붉은바위 고원 | 동쪽 | 8-12 | 고블린 약탈자 (야영지) |
| 잊혀진 묘지 | 남쪽 | 12-16 | 해골 전사 |
| 잿불 화산지대 | 서쪽 | 16-22 | 화염 임프(원거리), 👑 보스 **고대 골렘** |

### 시스템
- **퀘스트**: 촌장 엘다의 6단계 메인 퀘스트 → 이후 레벨에 맞는 반복 토벌 퀘스트
- **성장**: 최대 30레벨, 레벨업 시 체력/마나 완전 회복
- **장비**: 직업별 무기 5단계, 공용 방어구 4단계 (등급별 색상/외형 변화). 상점 구매 또는 몬스터 드롭
- **협동 플레이**: 함께 때린 몬스터는 기여한 모든 플레이어가 경험치·골드·드롭을 획득
- **자동 사냥(AUTO)**: 레벨에 맞는 사냥터로 이동해 자동으로 공격하고 스킬·물약을 사용
- **채팅**: 전체 채팅, AI 모험가(이름 옆 `AI` 표시)들이 인사에 답하기도 합니다
- **저장**: 온라인은 서버(`data/players.json`), 오프라인은 브라우저에 자동 저장

## 조작법

| 동작 | 모바일 | 키보드/마우스 |
| --- | --- | --- |
| 이동 | 화면 왼쪽 아래 드래그 (가상 조이스틱) | `W A S D` / 방향키 |

| 대상 선택 + 공격 | 몬스터 탭 | 클릭 / `Tab` |
| 기본 공격 | ⚔️ 버튼 (가까운 적 자동 선택) | `Space` |
| 스킬 | 스킬 버튼 3개 | `1` `2` `3` |
| 물약 | 🧪 / 💧 | `Q` / `E` |
| 자동 사냥 | AUTO | `R` |
| NPC 대화 | NPC 탭 또는 하단 대화 버튼 | `F` |
| 가방 / 지도 / 캐릭터 | 우측 상단 메뉴 | `I` / `M` / `C` |
| 채팅 | 💬 | `Enter` |

## 구조

```
server/index.js      정적 파일 서버 + WebSocket + 게임 루프(10Hz) + 저장
shared/data.js       직업·스킬·아이템·몬스터·퀘스트 데이터
shared/terrain.js    결정론적 지형/지역/장식물/충돌 (서버·클라이언트 공용)
shared/world.js      월드 시뮬레이션: 전투, AI, 보상, 퀘스트, 봇, 스냅샷
public/index.html    게임 화면, HUD
public/css/style.css 모바일 UI 스타일 (세이프 에어리어, 가로/세로 대응)
public/js/main.js    클라이언트 메인 루프: 입력→이동 예측→전투→카메라→렌더
public/js/scene.js   지형, 하늘, 호수, 마을, 나무(인스턴싱), 지역 분위기
public/js/models.js  로우폴리 캐릭터/몬스터 모델 + 애니메이션
public/js/merge.js   드로우콜 최적화를 위한 메시 병합
public/js/entities.js 스냅샷 보간, 이름표/체력바, 피격 효과
public/js/fx.js      파티클, 투사체, 범위 링, 데미지 숫자
public/js/ui.js      HUD, 가방/상점/퀘스트/지도/설정 패널, 미니맵
public/js/input.js   가상 조이스틱, 카메라 드래그, 핀치 줌, 키보드
public/js/net.js     온라인(WebSocket) / 오프라인(로컬 월드) 연결
```

### 네트워크
- 서버가 모든 전투 판정·드롭·경험치를 처리하고, 클라이언트는 이동을 예측한 뒤 서버가 속도/지형을 검증합니다.
- 각 플레이어에게는 반경 80 이내의 엔티티만 전송합니다(관심 영역 관리).
- 메시지는 JSON이며 연결당 초당 메시지 수와 크기를 제한합니다.

## 그래픽 설정
설정(⚙️)에서 그래픽 품질을 바꿀 수 있습니다. 모바일 기본값은 **보통**(그림자 없음, 해상도 1.5배 제한)이며, **높음**은 실시간 그림자를 켭니다. 배터리를 아끼려면 **낮음**을 선택하세요.

## ⛳ 보너스: 솔바람 골프 (모바일 3D 골프)

`golf/index.html` 한 파일로 된 **가로형** 9홀(파 36) 3D 골프 게임입니다. 서버 없이 파일을 브라우저로 열거나 정적 호스팅에 올리면 바로 플레이할 수 있습니다(Three.js는 CDN에서 불러옵니다). 세로로 들고 있으면 화면이 자동으로 가로로 돌아갑니다.

- **라운드 준비**: 20종(우드·유틸·아이언·웨지) 중 13개를 골라 백 구성(퍼터는 항상 포함), 컨시드 2m/1.5m/1m/없음, 바람 켜기/끄기
- **템포 스윙**: 오른쪽 패드를 아래로 당겨 백스윙 → 위로 휘둘러 임팩트. 다운스윙이 너무 빠르면 좌우 미스, 너무 느리면 비거리 손해, 휘두른 방향이 비뚤면 당겨 치기/밀어 치기
- **그린 경사**: 경사 화살표와 흐르는 점(그린 읽기), 발밑 경사계, 휘는 방향·오르막/내리막 안내
- **라이 경사**: 왼발 오르막/내리막, 공이 발보다 높음/낮음이 탄도와 방향에 영향
- **연습장**: 드라이빙 레인지(20종 모든 클럽, 캐리·런·좌우 편차 표시), 퍼팅 연습장(거리별 라인, 성공률)
- **자연 소리**: 바람, 나뭇잎, 새소리, 까치, 물소리(해저드 홀)
